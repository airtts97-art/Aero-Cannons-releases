# v2026.11.23-2 OPの所持品制限除外

試合の所持品整理から、サーバーのOPリストに登録されているプレイヤーを除外します。OPのインベントリ・装備・カーソル上のアイテムを削除・減量せず、個人インベントリへの格納も制限しません。試合開始・ログイン時の足場アイテム回収もOPを除外します。一般プレイヤーの制限は維持します。

共有倉庫や船の搭載品の検査、設計図のレギュレーション検査を無効化する変更ではありません。

MAP前後修正、見張り結果を次の見張りまで保持する修正、船内の回転衝突保護、艦艇配置時の船底余裕、および従来の乗員UUID・DH負荷対策を含みます。

本番は告知・保存・ワールドバックアップ後に適用し、再起動とボイスチャット待受を確認しました。参加用インスタンスも同じJARに更新しました。オンラインプレイヤーの所持品を変更せず、切り離した試験用プレイヤーでOPの所持品保持と一般プレイヤーへの制限継続を確認しました。
