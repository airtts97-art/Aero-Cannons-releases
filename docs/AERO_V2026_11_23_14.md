# v2026.11.23-14 — 延焼先の寿命を独立

延焼で新しく生まれる火は、元の火の消火期限とAGEを引き継がず、新たなAGE 0の火として約30秒～3分の期限を決める。

各火は自然消火するが、さらに別の場所へ延焼し続ける場合、火災全体は3分を超えて続き得る。既存の火を延焼処理で更新して寿命を延ばす処理は追加していない。延焼確率6倍、判定周期、通常の消火処理はv13と同じ。

確認：Java 21でビルド成功。v13との成果物差分がCombatFireとバージョン情報だけであることを確認。v13の「同じ期限を引き継ぐ」という検証結果は、この版の延焼先には適用しない。今回のゲーム内動作確認・本番反映は未実施。
