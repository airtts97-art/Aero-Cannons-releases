# 艦載機パイロットの連続飛行確認（2026-11-18）

対象：Aero Cannons v2026.11.18-30。専用サーバー上の隔離区域で、同じNPCと同じSable機体を使い、全工程を完了しました。

| 工程 | 実測結果 |
| --- | --- |
| 自力離陸 | 甲板上で静止した状態から加速し、速度安定を3回確認して離陸・上昇 |
| 哨戒 | 約600ブロックの区間を出発側→反対側→出発側の順で往復 |
| 自動爆撃 | CBCMoreShellsのAPHE爆弾を高度約120から投下し、高度約64.5の指定標的に命中 |
| 標的の損傷 | 標的サブレベル内の石への着弾・貫通を記録。標的質量が3026から3024へ減少し、石1ブロック分の欠損を確認 |
| 帰還・着艦 | 進入線へ合流し、指定した静止甲板へ着艦。接地後も減速を継続 |
| 停止 | 14:03:57 JSTに着艦完了。移動速度・回転速度はいずれも (0, 0, 0)。操縦用キーの信号も解除 |

飛行中に機体をTPしたり、外力で押したりする補助は行っていません。各任務への切り替えはコマンドで指示しました。最初の着席は試験準備としてコマンドで行っています。

試験機は、提供された機体から舵の設定・脚・爆弾位置を調整したコピーです。元の設計図ファイルは変更していません。設計図読み込み直後の一時固定が解除され、機体が甲板上に落ち着いてから試験を開始しました。

今回の命中確認は上記APHE爆弾によるものです。300ブロック以上からの投弾、他の弾種、移動中の母艦への着艦、名簿画面の操作は、この連続試験の確認範囲に含めていません。旋回中には数〜10ブロック程度の高度変動が残ります。

## 修正した原因

- 短い信号の切れ目で舵が中立へ戻り続ける問題：強さを調整した信号を保持し、反対操作や中立へ移る際に解除。
- 高度復帰中に進路修正が止まる問題：翼を水平に戻しつつ小さくヨーを操作。
- 高度の残留誤差を補正し切れない問題：補正の蓄積を止める条件を、実際の上限に合わせて修正。
- 着艦入口の一点の周囲を回る問題：手前の合流点から滑走路の延長線へ進入。
- 接地前の減速による失速：接地判定までは進入速度を維持。
- 甲板より高い位置を飛び続ける問題：最終進入中も降下速度の誤差から補正を更新。

## 環境と確認

Minecraft 1.21.1 / NeoForge 21.1.258 / Sable 2.0.5 / Nepheria Gloud 1.0.0 / Java 21。

離陸速度判定と高度補正の上限判定の回帰テストも通過しています。今回追加したコードは実サーバーで動かして確認しました。試験用の船体と強制読み込みは終了後に撤去しています。
