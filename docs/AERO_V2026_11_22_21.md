# v2026.11.22-21 艦艇配置時の船底余裕

試合準備で新たに配置する船は、全構造体の実際の境界を確認し、最も低い部分をドック上面から16ブロック離して配置します。傾斜や、上下に離れた部品も含めます。配置後の補正では部品間の位置関係を維持し、一時固定の固定点も更新します。

`config/aerocannons-performance.toml` の `matchSpawnClearanceBlocks` で0～64ブロックに変更できます。既に配置済みの船は移動しません。試合開始時に固定を解除した後は、正常な浮力・推力が必要です。この設定だけで落下を防ぐものではありません。

既存の乗員UUID再生成対策・専用サーバーDH負荷制限を維持し、通常額縁とInteriors大型座席の設計図許可も内蔵します。

## 確認

隔離サーバーで、傾斜0/±35/80度、上下に離れた子構造体、実際の救出前設計図を確認。ドック上面81に対して船底97となり、配置後補正でも固定点を含めて移動できました。設定0および不正値の拒否も確認しました。

## 別件の機関室試験

破損前の保存船のコピーで、機関室付近のレバー12個をONにし、エンジンへ空気とディーゼルを補充しました。エンジン起動段階でOmniスピードコントローラーがCreateの回転伝達処理から破壊されることを再現しました。呼び出し位置はCreate 6.0.10のRotationPropagator.java:272で、同一ネットワーク内の速度増幅を検出する分岐です。

続いてSableの船体分割と、Simulated側のからくりディスアセンブルが記録されました。発砲数は0で、発砲を原因とする試験は成立していません。分割処理が先行したため、その後の動的試験も有効な検証として扱いません。

この版は上記の機関室破損を修正した版ではありません。個別の回転系接続と保存・復元との関係は追加調査が必要です。隔離試験を終了して試験環境の設定を復元しました。本番への適用は行っていません。
