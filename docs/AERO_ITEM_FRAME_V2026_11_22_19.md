# 設計図内の額縁を許可（v2026.11.22-19）

Minecraftの正しいIDは `minecraft:item_frame` です。試合用スケマティックの許可タグへ通常の額縁を追加します。既存の接着剤などの許可を維持する追加式データパックです。発光する額縁や他のエンティティの許可は変更しません。

Aero Cannons v2026.11.22-18をそのまま使用できます。JARの交換・サーバー再起動は不要です。手持ちアイテムの許可リストを変更するものではありません。

別の開催サーバーへの導入：ZIPを展開せず使用中ワールドの datapacks に配置し、OPで `/datapack list available` を実行後、`/datapack enable "file/aerocannons-match-item-frame-v2026.11.22-19.zip"` を実行してください。新規ワールドの起動時に配置済みなら自動検出されます。

本番のタグ読み込みと設計図のエンティティ審査で、額縁が許可されることを確認済みです。既存の接着剤の許可と、防具立ての禁止も確認済みです。
