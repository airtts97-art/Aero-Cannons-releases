# v2026.11.22-17 奈落を標準にした試合場と環境リセット

JAR内蔵の試合ディメンションを、溶岩・岩盤のない奈落に変更しました。ロビー、ドック、設計図登録、赤青1,500ブロック間隔、気圧設定、従来のNPC・武装・MAP・復活待ち表示などは維持します。奈落用の外部データパックは新規環境では不要です。

## 新規ワールド

このJARを導入して起動し、OPで `/aeromatch setup` を実行してください。溶岩版を定義する古い外部データパックがあるとそちらが優先される場合があります。新規ワールドでは取り外すか、以下の環境リセットを使用してください。

## 通常の試合リセット

`/aeromatch reset confirm`

配置済みの登録艦を片付け、ロビー状態へ戻します。登録設計図やOPサンプルを保持する従来のリセットです。地形を丸ごと再生成するコマンドではありません。

## 試合環境全体のリセット・既存の溶岩MAPからの移行

1. OPで `/aeromatch reset arena confirm` を実行します。
2. サーバーを通常終了して再起動してください。予約だけでは稼働中の地形は変更しません。
3. 次回起動時、試合ディメンションの地形・エンティティ・Sable構造体データと試合登録情報を `ワールド/aerocannons-match/arena-resets/<予約ID>/` へ退避します。
4. 奈落の試合場とロビーを再生成します。参加登録は解除されるため、チーム参加と艦艇登録からやり直してください。ドックは準備処理で再生成します。

現在存在する登録艦は、予約時に復元用NBTも保存します。未登録の船も含む試合ディメンション全体の退避は、正常終了後・次回起動時に行います。OPサンプル設計図、既存の設計図ファイルとアーカイブ、オーバーワールドと他のディメンションは保持します。

既存の溶岩版データパックにも対応するため、予約時に `datapacks/aerocannons_void_default.zip` を作成して次回起動時の優先設定に追加します。変更済みの試合場を元に戻したい場合は、サーバーを停止してバックアップの arena と aerocannons_match.dat を対応する元の場所へ戻し、地形設定のデータパックも元へ戻してください。稼働中のファイルの差し替えはしないでください。

奈落版でも現在のJARの脱落条件（船の全体がY=20未満で200tick）は維持します。溶岩による燃焼・接触ダメージは発生しません。

## 確認範囲

別環境で、新規ワールドのJAR標準による奈落生成、ロビーとドック生成を確認。さらに旧溶岩データパックが有効な状態から、OPコマンドで予約、正常終了と再起動、旧試合場の退避、奈落とロビーの再生成、他ディメンションとOPサンプルの保持を確認済みです。本番と参加用インスタンスには自動適用していません。船・NPC付きでの溶岩版との負荷比較は未実施です。
