# v2026.11.21-19

弱い回線向けにプレイヤー別の通信量削減を追加。`/aeronetwork lowbandwidth on` で有効、`off` で解除、`status` で確認できる。初期状態は無効。設定は本人に保存され、再接続時にも適用。OPなしでも自分の接続を変更可能。

対象のエンジン・パイプなどの機械状態について、同一内容の繰り返しを省き、連続する表示更新を最大0.5秒単位の最新状態にまとめる。対象外のパケットは通常送信。ブロック置換・チャンク再受信・別ディメンションへの移動ではキャッシュを破棄し、最初の状態を必ず送信する。対象キャッシュ最大4096件、終了時は保留中の最新状態を送信。

本番の一時試験では同時刻の比較用接続に対し、ブロック内部データが9.38MB/10秒から1.81MB/10秒へ約81%減少。位置・視界・受信内容が完全に同一の比較ではないため、この割合は当該測定の範囲。TCP送信量を減らすものでインターネット経路そのものの変更ではない。SableのUDP、音声、ゲーム内計算はそのまま。

主砲・副砲の混合補充モードを追加。AP・APHE・対空弾を各16発、合計48発の目標在庫として、実在する同系統弾の近隣デポから不足する種類を運ぶ。既存アイテムの信管等の構成を維持し、素材や弾薬を生成しない。混合モードは運搬命令のextra=4803、目標value=48として指定。一般の数量指定運搬は従来挙動を維持。

立ち番の持ち場補正を船の姿勢変化に対応。Sableの継承移動後に残った位置ずれを補い、船の移動による1.5ブロック超のずれで任務を解除しない。床の喪失・衝突・任務変更などでは保持を解除する。歩行・着席・パイロット操縦は既存処理を継続。
