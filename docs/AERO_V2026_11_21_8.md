# v2026.11.21-8 — 整理要員の歩行引き継ぎ

v7の乗員チャンク維持、v6の甲板機体検出と発艦整理要求、v5の衝突検査軽量化を含む。

専用経路探索が行き詰まる場合、Nepheria標準の扉・階段を扱う歩行に引き継ぐ。船に固定された倉庫へ歩く経路は、無関係な機体の揺れだけで最初から再構築しない。移動する機体やエンティティとの衝突確認は維持する。

本番確認：同じ整理要員・同じ保管場所に対して、標準探索で到達可能な51地点の経路を約6.1msで取得。修正後、整理要員はX657付近からX611付近まで歩き、実在する simulated:plunger_launcher を1個取得した。状態は preparing_tow_walking（牽引準備で機体へ移動）に進んだ。牽引・整列・再発艦の一連の完了までは未確認。

サーバーの直近平均は24〜25ms/tick。状況が変わるため性能保証値ではない。JARは本番の次回起動用ファイルへも反映し、現在の実行中コードにも適用済み。クライアントのゲームは強制終了せず、終了後に参加用インスタンスへ差し替える。

兵士が見えなかった件では、地面に落ちた旧実体と船内へ復活した新実体を観測した。元の描画距離判定の試験変更は効果がなく撤回している。描画設定や移動検証の無効化によって症状を隠してはいない。
