# v2026.11.23-13 — 延焼と燃焼時間

- 延焼確率を従来の6倍に変更。1回の延焼判定あたり約4.9611%から約29.7668%。近くに着火できる場所がない場合や雨などの従来条件は維持する。
- 燃焼時間を火ごとに約30秒～3分でランダムに決定する。通常の火の最初の更新まで約30～39tick、以降の残存時間を570～3570tickから選ぶ。20TPSで約30～180秒（最初の更新の揺らぎを含め最大約180.45秒）。
- 火災による耐久損傷・延焼判定の通常の更新間隔は従来どおり240tick。燃焼時間を短くしただけで更新回数や秒間の延焼率がさらに増えないよう、消火期限を独立管理する。
- 延焼先は元の火のAGEと消火期限を引き継ぐ。消火・除去時には期限を破棄し、再着火時は新しく決める。
- doFireTickを無効にした間は期限も停止する。既存の消火経路での消火は可能。
- 期限は稼働中のワールドごとのメモリで管理する。再起動や保存コピーの配置などで期限がない火は、残りAGEの上限内で再設定する。絶対期限の永続保存は実装していない。

v11のMSロケット再装填、v12のMSロケット耐久消滅時起爆対応を含む。

## 検証

別環境で実際のFireBlockとMixinを使い、時間を進めて最短期限で消火すること、最長期限、一度決めた期限の維持、消火後の再抽選、延焼先へのAGE・期限の引き継ぎ、doFireTick停止を確認。確率の計算値が従来の厳密な6倍であることも確認した。実時間で3分待機する試験や大規模延焼時の負荷測定ではない。
