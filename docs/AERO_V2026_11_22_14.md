# v2026.11.22-14 乗員の復活時間表示

乗員名簿の左上の「復活待ち」から、乗員名と復活までの残り時間を確認できます。待機人数が多い場合はマウスホイールでスクロールできます。

- サーバーに保存されている残りtickを毎秒取得して表示します。20 tickを1秒として切り上げ表示します。低TPSでは実時間よりゆっくり減ります。
- 復活が無効の場合は「復活停止中」、タイマーが終了してベッドが用意できていない場合は「復活先のベッド待ち」と表示します。
- 名前が読み取れないデータは乗員IDの先頭8文字で区別します。
- 復活時間・復活条件自体は変更しません。従来の機能とv13の修正を含みます。

導入：サーバーと参加者の両方で旧Aero Cannons JARを置き換え、再起動してください。このリリースでは本番サーバーや参加用インスタンスへの自動適用はしていません。

確認：専用の別環境で起動・通信登録、復活待ちデータの名前・残りtickの抽出、異常値の処理、停止状態を含む送受信データの往復を確認。実際のゲーム画面での見た目確認は未実施です。
