# v2026.11.23-4 弾薬運搬・パイロット乗り込み

弾薬の補充先をブロックそのものに限定せず、3ブロック以内で実際に手が届き、遮蔽物のない周囲の足場を経路の到達候補にします。足場と身体の通行判定は既存の経路探索で確認し、移動して届いた場合だけ実在する手持ち弾薬を格納します。補充数・弾種・倉庫在庫は変更しません。候補の確認はサーバースレッドで分割し、全体で約1ms/tickの予算を設けています。探索本体の既存ワーカー処理は維持します。

通常歩行の経路計算がまだ準備中・実行中のとき、「到達不能」を根拠に別の階段へ切り替えないようにしました。

パイロットの乗り込みでは、探索側の2.85ブロック判定と実際の3ブロックの搭乗距離の差で、甲板端への経路が打ち切られる問題を修正しました。近くの候補地点から、足場・段差・身体・他エンティティとの接触を確認して最大0.3ブロックだけ接近位置を調整し、終点直前で早く停止しないようにします。実際の着席は従来どおり3ブロック以内です。浮動小数点誤差のみ微小な許容を設けています。

別環境のSable船上で、通常の運搬プログラムがAP弾16発を取り出して高い位置の樽へ実際に歩いて補充すること、タイプライターハブに紐付いた通常のパイロット任務が母艦の甲板を歩き、別機体の座席へ搭乗することを確認しました。試験用NPCの位置を途中で転送せず、通常の移動・搭乗処理を使用しています。
