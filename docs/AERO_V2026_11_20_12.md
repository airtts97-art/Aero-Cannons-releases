# v2026.11.20-12 — 通信士の空中線・自動同調

- 通信士の艦間情報共有と母艦の艦載機報告受信に、Nepheria Gloud 1.0.0 の AntennaNetwork.hasAntenna を使用。
- アンテナ碍子を置くだけでは不可。空中線で接続した有効な一対が必要。同じSable機体、地上では受信機から16ブロック以内という本来の判定を使用。
- 同じ艦隊名から周波数を自動設定。艦隊の一致判定も維持し、ハッシュ衝突だけで敵情報を共有しない。
- 本来のMorseNetworkと同じ距離区分：2,000ブロック以内は通常、2,000超～3,000は弱電波、3,000超は圏外。距離はワールド座標で評価。
- 原MODの弱電波では文字単位に雑音が入る。座標報告では壊れた座標を使用しないため、25%の確率で報告全体を破棄して次回を待つ。文字復号の完全な再現ではない。
- 空中線を失うと保留中の艦載機報告を破棄。既に受信した過去の情報は時刻付きで保持。
- 艦載機の専属通信士・送信機による高速報告には空中線が必要。既存のパイロット単独による遅い報告は維持。

## 確認

別環境のNeoForge 21.1.258サーバーで起動。実際の受信機・碍子・空中線リンクを作り、未接続/単独碍子の拒否、接続、切断、再接続、地上16ブロック、自動同調を確認。距離境界2000/3000、2001種類の艦隊名、保留報告の取消と過去報告の保持を確認。試験ブロックとリンクは終了時に片付けた。
NPCを乗せた実航行中の通信試験と弱電波の長時間統計測定は未実施。
JAR資源参照・Mixin収録確認、配布ZIPの177 MOD/CRC/秘密情報検査に合格。
