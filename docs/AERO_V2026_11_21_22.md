# v2026.11.21-22

試合登録画面の文字がぼける原因を修正。MinecraftのScreen.renderが、画面の文字を描いた後にrenderBackgroundを呼び、背景ぼかしを画面全体へ掛けていました。この画面ではrenderBackgroundを上書きし、ぼかしを実行しません。

艦名は設計図ファイル名とは別です。入力欄を「艦名（ファイル名とは別）」と明示し、未入力の案内とチーム未選択の事前確認を追加。チームを選び直した後も古いエラーが残る問題を修正しました。

登録手順: F9 → 試合MAPへ入る → 赤か青を選ぶ → 艦名を入力 → ＜／＞で設計図を選ぶ → 自分のファイルを登録。設計図はプレイ中インスタンスのSable-Schematics直下に置くPhotomancy形式の.nbt（16MiB以下）です。成功すると登録船とコストが表示されます。登録後に「準備OK」を選びます。ファイル名は変更されません。

CreateのAbstractContraptionEntityを継承する構造体を、MODの名前空間ではなく実際の型で判定します。Aeronauticsのpropeller_bearing_contraptionも対象です。内部ブロックのタフネス、禁止装備、コストを検査します。内部データ欠落、読めない構造体、未知のエンティティは登録できません。

導入環境の55種類のネザースチール砲部品をタフネス35・硬度1へ設定。元の硬度1は維持します。CBC本体・CBC AT・CBC Modern Warfare・CBCMSの対象部品と製造途中の部品を含みます。ネザライトの一般建材は変更しません。

確認: 別サーバーで更新JARを起動し、55部品の値を確認。実際に登録されたAeronauticsプロペラ構造体の型と、Createが保存・復元した内部ブロックを使い、ネザースチール閉鎖機の許可とコスト集計用の個数を確認。内部コマンドブロック、タフネス40超過、内部データ欠落、未知エンティティは拒否しました。試験はメモリー上の構造体で行い、本番の船やプレイヤーを変更していません。GUIの見た目の最終確認はゲーム再起動後に必要です。

v20の機関砲最大補充・誘爆寄与1/100、v21の担当NPC名表示も含みます。通信パケットの形式は変更しません。WARPのMinecraftへの経路切り替えは含みません。
