# v2026.11.21-18

ゲームルール `aeroLookoutChat` を追加。`false` で見張り員による船・敵の発見報告チャットを非表示にし、`true` で再表示。既存挙動を維持するため初期値はtrue。本番ワールドはfalseに設定。

観測・攻撃目標・航空機MAPへの共有・警報音は継続する。検出処理の結果や対象を変更せず、native shipAlarm/alarmからのチャット送信のみを切り替える。

Create座席に着席済みの見張り員がonGround=falseのため任務開始前で止まる不具合を修正。同じ母艦の指定持ち場に近い通常見張り員のみ到着を認める。パイロットや遠方のNPCは対象外。

別環境で実際のnative報告処理を呼び、表示ONで2件、OFFで0件、再ONで1件の送信を仮プレイヤーで計数。またOFFのまま着席見張り員が任務を開始し、観測情報3件を蓄積することを確認。
