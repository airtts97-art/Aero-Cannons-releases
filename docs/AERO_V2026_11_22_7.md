# v2026.11.22-7 — 発艦前点検・甲板通路・信管・爆弾

- 母艦上で加速・ドッキング解除信号を送る前に、発艦方向と任務用の弾薬を確認します。方向差12度超、中心線から3ブロック超、弾切れ、装填状態不明なら発艦を止めて整備を要求します。
- 対艦攻撃は対艦武装、対空攻撃・護衛は対空武装を点検します。訓練・移動・哨戒には弾薬を要求しません。
- 待機中の飛行命令を保持したまま、整備員が不足する爆弾・信管を実物の補給品から取り付けられます。補給と向き直しを別の整備理由として扱います。
- 整理員の歩行経路を通路中央へ寄せ、手すり付き通路で初期位置に偏った探索をしないようにしました。壁・手すり・他機体との衝突判定は維持します。
- v6の帰投・着艦通知を含みます。機体番号・機体名・母艦名を味方の船上プレイヤーと同じディメンションのOPへ通知します。
- 時限遅延信管は最初に1ブロックを破壊した衝突でタイマーを開始します。弾痕・ヒビだけでブロックが残った場合は開始せず、装甲を破壊してからカウントします。感度表示は1です。設定した遅延時間は保ち、次の衝突でタイマーをリセットしません。
- 爆発する弾は貫通耐久が0になった衝突で遅延を待たず起爆します。CBC・CBCMS・CBCATの対象経路を対応し、非爆発のAP Shotは除外します。CBCMS爆弾はこの即時起爆時に投下直後の威力0制限を受けません。
- CBCMS徹甲爆弾の爆発パラメータは16、HE爆弾は64です。CBC純正の大口径HEの対ブロック値8に対して2倍・8倍です。破壊範囲・最終ダメージがそのまま2倍・8倍になる意味ではありません。

## 確認

本番と分離した専用サーバーで起動しました。

- 実物のCBCMS爆弾を使って、逆向き・空・装填不明での拒否、補給後の許可、命令保持中の再取り付けと補給品1個の消費を確認。
- 実物のNPCがSable船上の手すり付き試験通路を歩いて目的地へ到達。
- 着艦完了判定8サンプルと通知受信側を確認。機体名を含むメッセージが1回届き、無関係なプレイヤーには届かないことを確認。飛行から着艦までの一連の実機飛行試験ではありません。
- CBC・CBCMS・CBCATの起爆処理を実行し、貫通耐久0で即時起爆することを確認。徹甲爆弾16・HE爆弾64も起爆時の値で確認。試験では爆発イベントで地形破壊を止めています。
- CBCMSのAPHEは実際の弾道・起爆処理と、記録用の補助サービスを使って確認。長い遅延を設定しても耐久0で即時に起爆処理へ進みます。
