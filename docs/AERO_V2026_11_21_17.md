# v2026.11.21-17

発艦時に母艦情報を取り逃がした場合も、母艦滑走路の近くでは母艦情報を再取得し、逆向きや中心線から外れた機体は加速せず減速する。向きの不一致で停止すると全舵入力を解除し、駐機を確認できたら整理要員に要求する。駐機の接地検査に機首・尾部寄りの四隅を追加。

Nepheria Gloud 1.0.0の照準用砲架認識・角度・回転中心の取得にCBC Compact Mount 1.2.2対応を追加。純正砲架とは異なる隣接ブロックの回転中心を利用する。通常砲架の既存の読み取りを優先し、対象MODがなければ互換Mixinを読み込まない。

確認範囲は試験結果ファイルに記録。動的な飛行やレッドストーン追従の長時間確認とは区別する。

別環境で互換Mixinを読み込み、コンパクト砲架の4方向の認識・角度・回転中心、未組立・撤去時の除外を確認。また、試験機体の姿勢と発艦状態を設定して、実際の航法処理が母艦情報を再取得し、逆向きで全舵解除・減速を出すことを確認。飛行全体・レッドストーン追従の継続試験とは別の判定試験。
