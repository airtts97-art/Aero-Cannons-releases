# v2026.11.22-8 艦載機の編隊・順次発艦・駐機場所

同じ母艦・任務・目標・武装の機体をまとめて指示すると、同じ編隊に振り分けます。爆弾の種類や砲の構成・弾種が異なる機体は別編隊になります。武装を読み取れない機体は混ぜません。

## 順次発艦と攻撃

- 名簿の航空機MAPで複数機を選び、同じ任務を指示します。
- 先行機が母艦の上空へ離陸してから最低60tick（20 TPSで3秒）間隔で次の機体を発艦させます。従来の甲板占有・障害物・向き・弾薬の確認も行います。
- 発艦後は母艦前方の集合場所で待ち、集合後は機体の大きさに応じて間隔を空けて追従します。目標付近では各機が攻撃へ移ります。
- 命中判定は編隊全機のANDにはしません。散布の中心・左右・上下の候補弾道のうち、実際に標的ブロックへ到達するものがあれば、その機体の射撃判定を通します。これは命中保証ではありません。
- 弾薬、再装填、味方への射線、読み込み済みの経路などの確認は維持します。命中の見込みがない機体まで無条件で撃つ処理ではありません。
- 整備できない僚機を待ち続ける場合は、その機体の任務を中止すると残りの機体が進行できます。

## 専用駐機場所

1. 滑走路マーカーを持ち、Shiftを押しながら空中を右クリックして「駐機場所」モードにします。モードは着艦→発艦→駐機場所の順で切り替わります。
2. 甲板の上面を右クリックして駐機中心を選び、もう一度、機首を向けたい方向の甲板上面を右クリックします。
3. 待機列として使いたい位置に必要数を登録してください。翼幅と整理員の作業空間を確保し、滑走路を塞がない配置にします。
4. マーカーを持っている間は紫の粒子で表示します。駐機場所モードで中心付近を左クリックするとその場所を削除します。

整理員は待機機を空いている駐機場所へ移動します。空きがなければ待機します。場所はワールド再起動とSableスケマティックの保存・復元に対応し、復元先では予約を引き継がず新しい場所として登録します。

## 確認範囲

別サーバー環境で起動し、Sableの実体を使って駐機場所の排他予約、スケマティックへの情報保存、武装別の編隊分離、60tickの順次発艦判定、隊形間隔、任務保存・復元、中心弾道が外れて散布候補だけが当たるOR判定を確認しました。

実際の複数航空機による一連の発艦・集合・移動目標への命中までは未確認です。機体の操縦特性と甲板配置に依存するため、実機での調整が必要です。

v2026.11.22-7の発艦前点検、整備要求、着艦通知、手すり通路対応、信管・爆弾の変更も含みます。
