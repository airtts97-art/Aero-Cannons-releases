# v2026.11.21-4 訓練の旋回学習（後続v8にも同梱）

訓練の基本舵試験後、左右それぞれ360度の旋回を行う。バンク角を20度、35度、50度と段階的に上げ、高度・速度を維持した継続旋回から左右別の最大旋回速度とバンク角を保存する。高度低下・低速・障害物を検出した場合は回復を優先する。

完了した学習値は約20度を超える方向転換で使用し、小さな方向修正、着艦、高度回復、精密射撃では専用制御を優先する。機体重量または操縦割当が大きく変わった場合は旋回プロファイルを採用しない。ワールドとSableスケマティックに完了した旋回プロファイルを保存する。

検証：別サーバー上で制御された疑似姿勢を入力し、左右一周の完了、両方向の安定旋回サンプル、保存と読込、高度逸脱時の回復への移行に合格。実機の自由飛行での左右一周と着艦は未確認。当初の候補をv4で本番へ反映し、後続v8にも同梱している。実機の自由飛行検証は未完了。

関連変更：登録昇降口へのネイティブ経路引継ぎは別環境のSable二層船体で選択・解除を確認。物理的な階段の完全踏破は未確認。移動甲板予測と距離別許容幅は数値試験済み。通信士のレポート待機が途切れる問題への修正は実運用での継続受信確認が残る。
