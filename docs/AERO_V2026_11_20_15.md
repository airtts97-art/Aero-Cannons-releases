# v2026.11.20-15 — 着艦成功条件の緩和

中心線に合わせる進入制御はv14から維持。着艦成功の認識を誘導の精密条件から分離。

- 母艦の甲板を機体底面の中央・左右3点中2点以上で検出。
- 母艦に対する相対速度が2m/s未満、機体上面が甲板上向きから60度未満。
- この状態を8回連続（20TPSでは約1.6秒）確認したら帰還完了。以前は25回/約5秒、最終速度1m/s未満。
- 成功認識には滑走路中心からの横ずれ、機首方位、最終進入フラグを要求しない。帰還命令中なら手動着艦や滑走路横への安全な駐機も完了可能。
- 甲板未検出、裏返り、速度超過、無効な数値は成功扱いしない。滑走路登録と帰還先の指定は引き続き必要。
- 脚の高い機体への甲板検出範囲は従来と同じ。

判定関数の境界・甲板必須・低速・傾き・裏返り・異常値を直接試験して合格。JAR資源参照とMixin収録を確認。実機による帰還完了の通し試験は未実施。
本番はv13のまま。v14の経路Mixinも含むため、サーバー用ファイルは準備のみで再起動していない。参加用インスタンスはゲーム終了後に差し替え。
