# v2026.11.20-14 — 艦内歩行の回避と着艦中心線

- v13の給油変更を含む。燃料リンク先の全タンクの空き容量の合計が1,000mB以下なら給油完了。割合による95%完了・75%以上なら物資なしでも先に進む判定を撤去。リンク不明・未ロードを満タン扱いにしない。
- 通常乗員のネフェリア経路探索、パイロットの乗り込み、整備員の歩行で、他の生存エンティティ/物理障害エンティティを避ける。
- 自分自身、観戦者、死亡/削除済みエンティティ、当たり判定を持たないアイテムなどは障害物にしない。最初から重なっている場合は離れる方向への脱出を許可。
- 動的障害物の情報はサーバースレッドで取得し、短時間キャッシュ。移動するSable機体に乗る障害物はその機体に追従する座標で保持。
- 経路が塞がる/進まない場合は失敗した経由地点を一時的に回避。繰り返すと回避範囲を拡大。探索予算と距離上限は維持。
- 着艦は機体の外形境界の中心を使って中心線誤差を求める。操縦の基準原点とのずれも誘導点に反映。
- 最終進入開始条件：中心線から0.75ブロック以内、母艦に対する横滑り0.04ブロック/tick以下、甲板面内の向きが滑走路方向に約5.7度以内。高度条件も維持。間に合わなければ進入復行する。
- 最終進入中も中心線への補正と横滑りの減衰を継続。物理的に完全な誤差ゼロを保証するものではない。
