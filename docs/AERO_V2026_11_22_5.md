# v2026.11.22-5 — CBCATロケットの貫通・爆発調整

CBCAT 0.1.4c と配布ファイル cbcatfix-1.1.4.jar（内部バージョン1.1.0）の組み合わせを対象にしています。

## 変更

- 小型・中型・大型の戦闘用ロケット11種類の貫通係数を2倍。
- 衝突計算に限って運動量を2倍、貫通時の残存質量の消耗を1/2。飛行中の実速度と発射質量は変更しません。
- HE・焼夷・破片・対空・HEATのロケット弾頭で、CBCの対ブロック・対エンティティ爆発パラメータを1.5倍。最終ダメージが単純に1.5倍になる意味ではありません。
- 中型・大型HEATロケットのジェットエネルギーを2倍。ジェットの最大長は従来どおりです。
- 通常の機関砲弾・重機関砲弾・他MODの武器には、この追加補正を掛けません。
- 初速・推進・燃焼時間・重力・空気抵抗・誘導・信管設定は変更しません。

貫通係数だけでは、装甲の硬度をすでに上回った後の貫通枚数が増えないケースがありました。そのため、ロケットの衝突時の運動量と消耗も独立して調整しています。

## 設定

`config/aerocannons-ballistics.toml` に起動時に追加されます。4項目をすべて `1.0` にすると今回の補正を解除できます。

```toml
cbcatRocketPenetrationMultiplier = 2.0
cbcatRocketImpactMultiplier = 2.0
cbcatRocketExplosionPowerMultiplier = 1.5
cbcatRocketJetEnergyMultiplier = 2.0
```

## 確認範囲

本番と分離した専用サーバーで起動し、実物のエンティティとネイティブの衝突・起爆処理を呼び出して比較しました。

- 戦闘用ロケット11種類で貫通係数の増加と、質量・重力・空気抵抗の不変を確認。
- 爆発を持つ8種類で爆発パラメータの1.5倍化を確認。
- HEATの石の試験壁の破壊枚数は、中型3→6、大型6→12。
- 鉄ブロックへの垂直衝突処理を繰り返した試験で、APの破壊枚数は小型2→4、中型2→4、大型4→8。各サイズの既存の最高速度（9・6・4.5ブロック/tick）を入力しています。
- 末尾のブロックで弾の残存質量がゼロになる場合を含むため、これらは「破壊枚数」であり、全枚数の背後に弾が抜け出したという意味ではありません。
- 通常のCBCAT弾13種類の弾道プロパティに、この追加貫通補正が掛からないことを確認。
- 起爆処理のスコープは例外時も解除され、後続の通常弾へ補正が漏れないことを確認。

発射装置からの連続射撃、移動するSable船への命中、距離別の実射枚数は今回の確認範囲に含めていません。本番サーバーと参加用インスタンスへの適用は行っていません。
