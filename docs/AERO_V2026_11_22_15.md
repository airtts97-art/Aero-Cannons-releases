# v2026.11.22-15 名簿の正面を基準にしたMAP

攻撃目標レーダーと艦載機指揮MAPの上方向を、乗員名簿ブロックの正面に統一しました。Sable上では名簿の向きを船の姿勢でワールド座標に変換し、船が旋回すると表示も追従します。

- 目標の点、クリックによる目標選択、地点指定、ドラッグ移動と拡大縮小を同じ座標変換で処理します。
- 名簿が読み込まれていない場合や正面を水平に投影できない場合は北上表示に戻します。
- v14の復活待ち時間表示と従来の修正も含みます。
