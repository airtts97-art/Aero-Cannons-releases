# v2026.11.22-4 — 試合ワールドの気圧

- Aero CannonsのJARに `aerocannons_match:arena` 向けの気圧曲線を標準搭載。
- 既存の気圧4000mデータパックと同じ曲線を使用。通常世界のデータパックも残す。
- 更新データパックには試合用ワールドの項目を追加。JAR単体でも試合用の気圧が有効になり、外部データパックで上書きできる。
- 試合用追加項目は気圧のみを設定し、重力・共通抵抗・磁北の既存設定は変更しない。
- v2026.11.22-3の足場配布・NPC復元・ロビー修正・Nepheria Gloud 1.1.0を含む。

確認: 別サーバーの試合用ディメンションでJAR内の設定が選択されること、各高度での気圧とSable標準の推力補正式、4000ブロックの上限、重力と抵抗が変わらないことを検証。実際の船の重量に対して十分な加速が得られるかは、回転中の実機で別途確認する。
