# タイプライター基準の機体設定と実数爆風ダメージ

- 名簿 → 艦載機指揮 → 機体・パイロット設定で機体とタイプライターハブを選ぶ。
- 機首はハブの facing に合わせる。パイロット座席は同じ機体の上下左右前後の隣接座席から自動選択。複数なら背面、右、左、前、上、下の順。
- 操縦キーは、そのハブから Drive By Wire の接続先へ割り当てられているキーだけを選択する。未接続キーは表示しない。
- ハブを変更すると操縦キーの割り当ては解除する。保存してから出撃する。
- 滑走路マーカーを片手に持つと、128ブロック以内の設定済み滑走路を着艦＝水色、発艦＝緑で表示。最初の選択点は黄色。本人だけへ10tick間隔、最大128点を送る。
- 機体設定・補給武装画面の背景ぼかしを廃止し、半透明背景へ変更。役割ラベルはウィジェットの後に描画する。

## 武装選択
名簿 → 艦載機指揮 → 機体・パイロット設定 → 対象機体 → 補給・武装。
対艦武装／対空武装のボタンで対象の砲架または爆弾を選び、保存する。
タイプライター経由で撃つ装備は、機体設定の対艦攻撃／対空攻撃に、実際に配線した発砲キーを選ぶ。
砲架を使う装備は装填・アセンブルも必要。直接投下は機体上のCBCMS HE/APHE爆弾およびその跳躍型が対象。

## 爆風ダメージ
追加の耐久損傷は、固定割合ではなく実数で計算する。
D = 爆発力 × (100 × artillery.underwaterBlastWearFraction) × max(0, 1 - 距離 / 影響半径)
影響半径は爆発力の2倍。弱い爆風は平均硬度×blastMinimumHardnessRatioで無効化し、遮蔽判定を維持。
既定値0.35、TNT爆発力4なら、距離0/2/4/6で140/105/70/35。
実効靭性 = 元の靭性 × (1 - 現在の損傷割合)。
最終D = max(0, D - 硬度×5 - 実効靭性×4)。
からくりは平均硬度・1ブロック当たりの平均靭性・共有損傷割合で各被弾部の軽減を計算し、最終Dの合計を共有耐久から消費する。
損傷によって下がるのは爆風軽減用の実効靭性であり、最大耐久の基準値は固定する（最大耐久の再計算による二重損傷を防ぐ）。
通常ブロックはDを靭性×10×耐久倍率で割り、既存の損傷記録へ変換する。
耐久倍率3でも実数Dは変わらず、最大耐久だけが増える。通常のTNT直接破壊は別処理。

## 確認状況
Java 21コンパイル、実数爆風ダメージの不変条件試験、からくり耐久の既存試験を実施。
ゲーム画面での見た目・クリック操作および新ハブ登録の本番実機試験は未実施。

硬度3・靭性20に、2ブロック離れたTNT（元ダメージ105）が当たる例：無傷10、残り耐久50%なら50ダメージ。軽減が元ダメージを超える場合は0。
