# v2026.11.23-5 射撃指揮画面の目標保持

射撃指揮画面を閉じて開き直しても、選択した攻撃目標、砲塔のON/OFF、目標と砲手の表示情報、ページ、表示範囲を保持します。選択途中の内容も保持しますが、画面を開いたことを理由に攻撃命令を送信しません。

最新の通信で見えなくなった選択目標は灰色の点と「最終確認・現在未受信」で表示します。受信していない情報を現在位置として扱わず、再受信したときに新しい情報へ更新します。最新情報のない砲塔・目標だけの組み合わせでは攻撃命令ボタンを有効にしません。サーバー側の視認・味方判定・射撃許可は従来どおりです。

画面の記憶は接続・ディメンション・名簿・Sable船IDごとに分け、別の接続や、同じ保存領域が再利用された別船へ引き継ぎません。接続ごとに最大64名簿まで保持します。対象数は通信形式の上限64件以内に制限します。

既に発行した砲塔別の攻撃命令が残っていても、画面の選択表示だけが空になる問題も修正しました。再表示時の応答に、砲塔へ割り当て済みの目標を反映します。自動発砲設定・照準制御・信管・貫通・砲の角度制限は変更しません。

確認：画面状態の保存・復元、選択解除の保持、順序の保持、接続と船の分離、キャッシュ上限の9項目。独立した試験サーバーでは、砲塔への目標割り当て後に再表示用情報が選択済みとなること、表示の復元が目標モードや命令を変更しないこと、視認の保持・喪失・再発見・船の削除に関する従来の確認を通しました。実際の画面表示の最終確認は参加用クライアントで行います。
