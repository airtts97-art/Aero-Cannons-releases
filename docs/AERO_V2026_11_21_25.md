# v2026.11.21-25 — 設置型リンクコントローラー

配布済みv23を基準に、リンクコントローラーの修正のみを追加。別途作業中のv24タラップ自動配置は含めない。

- Drive By WireのRETURNフックへ到達する前に操作台の現在使用者を確認。前の使用者から遅れて届く押下・解除・終了入力が次の使用者を妨害する経路を遮断する。
- スペクテイターの押下は配線へ流さない。現在の使用者による解除・終了は維持する。
- Photomancyの保存・復元では、設置型コントローラーの一時的なUserを引き継がない。
- DriveByWireHubを保存対象の船体・ブロック参照で保存し、複数ハブ・複数コピーでもそれぞれの新しい座標へ変換する。保存対象外のハブは接続を引き継がない。
- 古い設計図の絶対ハブ参照は、同じ復元船体に候補ハブが1つだけの場合に補正する。複数候補を推測で選ばず警告する。複雑な旧設計図は元環境で保存し直す必要がある。

別環境の仮プレイヤー2名による実際のCreate入力処理とDrive By Wireの信号を用いて、交代・遅延解除・遅延終了・通常解除・スペクテイター拒否を確認する。さらに古い設計図の単一ハブ補正、同じ船体に複数ハブを持つ設計図の保存と2コピーへの復元を確認する。実プレイヤーの画面・異なるキー設定やネットワークを含む症状全体の確認とは区別する。

本番サーバー・参加用インスタンスにはこの作業では適用しない。プレイヤーごとの操作不能という報告について、今回の再現ケースが原因のすべてとは断定しない。

なお、このJARにはaeroLookoutChatはあるがaeroHydrodynamicsはない。浸水・浮力処理の一時停止には既存の /nihydro stop を使用する。
