# v2026.11.23-12 — MSロケットの耐久消滅時起爆

v11のロケット再装填対応を含む次回更新用候補。本番サーバー・参加用インスタンス・配布ZIPには未適用。

## 修正

MSのHE/APHEロケット、連装HE/APHEロケット、徘徊型HE/APHEロケットの6種類を、既存の耐久消滅時の起爆補正に追加した。

従来はFuzedRackedProjectileの衝突判定で起爆を要求できても、MSのdetonate実装が安全時間内の爆発力を0にしていた。貫通耐久（projectile mass）が0以下、爆発性弾頭、サーバー側、弾が未削除、位置のチャンクが読み込み済みという既存条件を満たす時だけ、detonate内の年齢判定を通過させる。

弾の実際の年齢、推進時間、速度、通常の信管処理、爆発力の設定値は変更しない。耐久が残る弾の安全時間は維持する。既存の徹甲爆弾とHE爆弾の対応を維持し、炸薬のないAP Shotは対象にしない。

## 別環境の検証

実際のMS投射物で、年齢0・耐久0および負値の着弾処理を実行し、各1回の爆発イベントと設定威力、対ブロック破壊が許可された爆発であることを確認した。イベントは開始時にキャンセルしているため、地形を破壊する実弾試験ではない。

| 種類 | 耐久消滅時の対物爆発力 |
| --- | ---: |
| HEロケット | 9 |
| APHEロケット | 4 |
| 連装HEロケット | 9 |
| 連装APHEロケット | 4.5 |
| 徘徊型HEロケット | 7.07 |
| 徘徊型APHEロケット | 3.5 |

耐久が残る年齢0の弾は、MS純正どおり威力0の爆発処理となることを確認。年齢100・耐久ありでdetonateを呼ぶ通常の年齢分岐も確認した。正常弾の信管から着弾までの通し試験ではない。徹甲爆弾・HE爆弾の耐久消滅時の着弾起爆も再確認した。
