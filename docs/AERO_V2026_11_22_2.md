# v2026.11.22-2 — NPC復元・試合ロビー・Nepheria Gloud更新

- Nepheria GloudをCurseForgeファイル9732891の1.1.0へ更新。配布JAR内部のバージョン欄は作者側で1.0.0のままのため、ファイル名とSHA-256で区別。
- SableスケマティックからのNPC復元を、船体の最終位置・重心の確定後に実行。既存のNPC命令・UUID再割り当て・名簿への紐付けはNepheria本来の処理を使用。
- ロビーに赤・青それぞれの艦名、コスト、参加者、準備状態を表示。長い一覧はスクロール可能。
- 書見台に設置した本を試合用倉庫の禁止品除去から保護。通常の倉庫・持ち物の許可ルールは維持。
- OP用 `/aeromatch prepare`、`/aeromatch start force`、`/aeromatch finish`、`/aeromatch status` を追加。通常のstartは維持。forceは乗艦判定のみ省略し、船・コスト検査を省略しない。
- v2026.11.22のリンクコントローラー修正・爆撃調整を含む。未完成のタラップ自動設置は含まない。

確認: 専用試験サーバーで1.1.0起動、Libertyを2隻復元して5人ずつのNPCと命令・所属を確認。書見台の本の保持、OP権限、コマンドの状態条件・終了時の登録データ保持を確認。UIのゲーム画面での目視確認は未実施。
既存の船から既に失われたNPCはこの更新で自動生成しない。元のスケマティックからの復元時に適用する。
既知の既存警告: NepheriaのSable計器互換初期化が専用サーバー上でClientLevelを参照し、対気速度・高度の取得が無効になる場合がある。1.0.0と1.1.0で当該クラスは同一。今回の更新で発生したものではない。
