# v2026.11.23-3 乗員の経路待機・密集脱出・別船ルート

非同期経路計算の準備中・計算中・処理上限による待機を、到達不能として階段の30秒ブラックリストへ登録していた問題を修正しました。最初の問い合わせ後も、準備処理を全体で1tickあたり約2msの予算内で順番に進めます。探索本体は既存の2ワーカーで実行し、ワーカーからワールド・エンティティは参照しません。

乗員同士が重なった開始地点を使用できるようにし、重なりが減る方向への脱出を許可しました。ほかの乗員へ深く入り込む移動は引き続き遮断します。

通常の階段ルート登録アイテムで、異なるSable船に置いた地点を1つのルートとして登録できます。各地点はそれぞれの船の座標系で追従し、参加する船の乗員名簿にもルートを共有します。片側で削除すると共有先も削除します。通常の同じ船内の経路処理は維持します。

使い方：ルート登録アイテムで、通行する足場を順番に右クリックしてください。出入口はShift＋右クリックで指定し、最後に空中をShift＋右クリックすると登録されます。別船の間には実際に歩ける橋・接続した甲板が必要です。登録だけで空中を渡ったり転送したりはしません。渡る地点間が3ブロックを超える、段差が1.15ブロックを超える、足場がない、通行が塞がる場合は待機します。長い橋には途中の地点も登録してください。登録は読み込まれた船と乗員名簿を対象にします。

独立した試験サーバーで、密集した2名の実移動、階段計算待ちで失敗登録されないこと、継続問い合わせなしで準備が完了すること、通常アイテムでの別船間登録、両側名簿への共有・削除、登録データのNBT往復、船を移動した際の地点追従、橋が離れた際の停止、NPCのA船→B船→A船の実歩行を確認しました。高速で相対運動する船間や、多段階の別ルートを乗り継ぐ経路を網羅した試験ではありません。
