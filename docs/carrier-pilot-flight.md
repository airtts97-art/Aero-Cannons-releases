# 艦載機パイロット：搭乗・飛行・着艦（2026-11-18）

## 座席への搭乗

機体・パイロット設定で指定した座席が、高さを含めて3ブロック以内にあれば、別のSable shipからTPして着席します。別shipの座席に座っていた場合も、元の座席を降りて乗り移ります。使用中の座席へは移れません。遠い場合は歩いて近づき、座席が失われた場合は操縦を停止します。

## 離陸用と着艦用を分ける

1. 滑走路マーカーを持ち、空中を向いてShift＋右クリックして用途を切り替えます。アイテム説明にも現在の用途を表示します。
2. 離陸用では、甲板の上面を「滑走開始点→発進端」の順に右クリックします。
3. 着艦用では、従来どおり「進入端→着艦中止端」を指定します。
4. 左クリックで削除するのは、選択している用途のペアだけです。

離陸用と着艦用の位置・方向は独立しています。逆方向への発進や、非全通甲板の一部に設けた区間も指定できます。指定した直線区間は障害物のない状態にしてください。機体はその方向に向け、中心線付近に配置します。自動でその場旋回して向きを反転する機能ではありません。

離陸用マーカーがない既存の船では、着艦用マーカーを出撃経路として利用します。甲板にマーカーがない場合は、出撃時の機首方向を使います。`aeroaircraft <船内のブロック座標> runway` で両方の位置と向きを確認できます。

## 離陸と安全高度

設計図を読み込んだ直後は、一時固定が解除され、機体が甲板上で落ち着いてから出撃させてください。試験でも、この待機後に命令を開始しました。

地上ではまず直進加速し、前進速度が9m/s以上で、速度の変化が小さい状態を3回続けて確認してから機首を上げます。前方が塞がっている、指定方向と機首が合わない、加速完了前に発進端への余裕がなくなる場合は待機します。短い甲板でも必ず離陸できるという意味ではなく、機体に合った加速距離が必要です。

巡航・哨戒・攻撃中に目標高度との差が8ブロックを超えたら、旋回・攻撃より高度復帰を優先します。差が3ブロック未満になり上下速度も落ち着いてから通常の旋回を再開します。高度復帰中も翼を水平に戻しながら小さくヨーを操作し、目標から離れる方向へ直進し続けることを防ぎます。爆撃中はその時の高度低下を新しい目標高度として扱わず、攻撃開始時の高度を維持します。

足元・前方の地表と障害物を調べ、機体寸法に応じた間隔を保つため必要なら目標高度を引き上げます。衝突回避は高度復帰より優先します。最終着艦では指定甲板への接地を許可します。下降速度も考慮して、地表へ近づきすぎる前に回避を始めます。

## 操舵と着艦進入

昇降・左右・方向舵は、必要な強さのタイプライター信号を次の制御まで保持します。中立や反対操作へ移ると前の入力を解除し、短いパルスの間に舵が中立へ戻り続けることを防ぎます。速度と回転速度にはSableの物理計算の値を使用します。任務切り替え時も、同じ機体の姿勢補正を引き継ぎます。

帰還では旋回と降下を並行し、着艦進入端の約400ブロック手前で滑走路の延長線に合流します。一点の周囲を回り続けず、延長線に沿って中心線と高度を合わせてから最終進入します。進入線の上空にも障害物のない空間が必要です。

最終進入中も、実際の降下速度と目標の差から補正を更新します。接地までは、予定の接地点を通り過ぎても進入速度を保ちます。接地前に減速して失速することを防ぐためです。接地後は約5秒以上減速を続け、相対速度が1m/s未満になってから着艦完了とします。減速入力は、その機体で実際にスロットルを下げたりブレーキを掛けたりできる操作へ割り当ててください。着艦後の機体固定には、すっぽんなどの機体側の仕組みを使ってください。

## 確認範囲

- 別shipの座席から指定機体の座席へのTP搭乗を実サーバーで確認しました。
- 速度判定は、停止・低速・加速中・安定・速度の揺れ・障害物待機後のリセット・不正な速度を実装と同じコードで確認しました。
- 着艦用と逆向きの離陸用マーカーを同時に読み取り、方向の内積が-1になることを確認しました。実サーバーで、向きが逆なら加速せず待機し、機体を離陸用方向へ合わせると加速入力が始まることを確認しました。
- 以前の試験版では、空中配置から約600ブロック先への移動と哨戒、低い標的とY=64の標的への自動投弾・命中を確認しました。標的には石1ブロック分の欠損がありました。
- v2026.11.18-30で、同じNPC・同じ機体の自力離陸→哨戒往復→APHE爆弾の命中→帰還→甲板上での停止を連続して確認しました。着艦後の移動速度・回転速度はいずれも0で、操縦入力も解除されました。[検証記録](carrier-pilot-flight-validation-2026-11-18.md)に条件を記載しています。

減速キーは、実際に機体を減速できる入力へ割り当ててください。スロットルを下げるだけの構成では、停止までの距離が長くなります。
