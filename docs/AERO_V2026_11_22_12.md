# v2026.11.22-12 複数船体の配置高度補正

試合MAPへの配置高度を、配置時と同じ座標系で計算するよう修正しました。

従来は主船体の向きにそろえたcanonicalBoundsを高さ判定に使いながら、実際には保存時の傾きを保って配置していました。このため、高さの異なる複数船体と主船体の傾きが組み合わさると、下側の船体が地面へ入り込む場合がありました。

今回の計算は、Photomancyの実配置と同じ姿勢変換を全船体の範囲に適用し、その最下点から配置高度を決めます。向きと船体間の相対位置は保持します。既に登録済みの設計図も、次の配置準備時に再計算されるため、この修正のための保存し直しは不要です。

別環境のSable 2.0.5・Photomancy 1.0.1で、高さが+12/-8ブロック異なる3船体を実際に保存・読み込み・配置して確認しました。

| 主船体の傾き | 修正前のめり込み | 修正後のめり込み |
| --- | --- | --- |
| 0度 | 0 | 0 |
| 35度 | 約3.73ブロック | 0 |
| -35度 | 未測定 | 0 |
| 80度 | 未測定 | 0 |

この試験は配置直後の初期姿勢を対象にしています。固定されていない船体の、その後の落下・旋回や動作による接地とは別です。

今回はJAR単体の更新です。ホストを終了してワールドをバックアップし、旧Aero Cannons JARと差し替えて再起動してください。前提MODの変更はありません。アーム物流・主船体のみの固定・NPC探索ワーカーなど、v2026.11.22-11までの変更も含みます。
