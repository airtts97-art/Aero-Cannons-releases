# v2026.11.22-3 — 乗艦用足場

v2026.11.22-2のNPC復元、試合ロビー、書見台、OPコマンド、Nepheria Gloud 1.1.0更新を含みます。

- タラップ車の自動配置を使用せず、乗艦準備中に参加者1人あたり足場を128個（64個×2スタック）配布。
- OPなしでも乗艦準備中だけ足場を設置・撤去可能。ほかのブロックと既存の船体は保護したまま。
- 設置場所と配布済み個数を試合データに保存し、再接続で重複配布しない。空きが足りない場合は空きができ次第残りを配布。
- 通常開始・強制開始で、固定解除前に準備中の設置足場と手持ち・カーソル・地面に落ちた足場を回収。試合中にログインする参加者の残存足場も除去。
- 中止・終了・次試合の準備でも回収。スケマティックに元から含まれる足場は記録外なので撤去しない。
- 別環境で非OPの配布・保護例外・保存復元・開始時回収・既存足場保持を確認。

操作: /aeromatch prepare → 足場を使って乗艦 → 各自「乗艦完了」→ OPが /aeromatch start。乗艦判定を飛ばす場合は /aeromatch start force。
