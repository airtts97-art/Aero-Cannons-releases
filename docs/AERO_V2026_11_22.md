# v2026.11.22 — 爆撃投下と進入旋回

v2026.11.21-25の設置型リンクコントローラー修正を含む。未配布v24のタラップ自動配置は含まない。

## 爆撃のみの変更

- 実際の爆弾の力・落下時間・機体速度・目標移動を使った予測は維持。
- 目標船の縁への実着弾を許可。甲板相当高度で船体外周から3ブロック以内の予測着弾も投下可能。角の許容距離は横方向の実距離で制限する。
- 爆弾だけにあった水平距離240ブロックの事前制限を1600ブロックへ拡張。距離だけで投下せず、予測軌道による判定を必須とする。高度差4〜350ブロック、弾の寿命、読み込み状態、障害物と味方判定は既存の条件を維持。
- 爆撃進入では、ロール左右・ピッチ上げが設定済みならバンクとピッチを組み合わせた旋回を優先し、最大約35度に制限。学習初期だけに限定しない。
- 爆撃中の中程度の高度ずれでは旋回を継続。高度ずれ24ブロック超や地形回避では高度回復を優先する。
- 着艦判定や着艦の最終進入バンク、機銃・砲弾・ロケットの厳密な着弾判定は変更しない。

## 確認範囲

独立したサーバー試験で、CBCMSのHE爆弾・APHE爆弾の本来の弾道計算を呼び、300ブロック高度の中央予測、旧判定で拒否される縁、新判定での縁・近接着弾、遠方の外れ、障害物、移動目標補正を確認。近接許容の境界・角、進入バンク符号と上限、高度回復ポリシーも確認。

投下判定と制御方針の試験であり、プレイヤー所有の実機を離陸から爆撃・帰投まで飛ばした試験ではない。本番・参加用インスタンスには未適用。
