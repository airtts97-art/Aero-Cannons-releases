# 試合用・奈落版MAP（v2026.11.22-16）

Aero Cannons v2026.11.22-15と組み合わせて使う、溶岩なしの試合用データパックです。新しいMOD JARへの交換は不要です。

## 内容

- 溶岩と岩盤を生成しない奈落の試合場。
- ロビーとドックは従来どおり /aeromatch setup、設計図登録、準備処理で生成します。
- 赤青の開始位置は引き続き1,500ブロック間隔です。
- 気圧4,000の試合場向けデータパックも同梱しています。
- 船のNBT保存・脱落判定などのJAR側の仕様は変えていません。現在の判定は「全パーツの上端がY=20未満の状態で200tick」を沈没扱いとするため、奈落版でもこの高度で脱落します。溶岩による燃焼・接触ダメージは発生しません。

## 導入（新しい試合用ワールド）

1. サーバーを停止し、既存ワールドと server.properties をバックアップします。
2. 別名のワールドを用意します。例：server.properties の level-name を aero-void-match にし、そのフォルダーと datapacks サブフォルダーを作成します。
3. 同梱の datapacks 内の2つのZIPを、その新規ワールドの datapacks に入れます。ZIPは展開しません。溶岩版の試合場データパックと同時に有効化しないでください。
4. サーバーを起動し、OPで /aeromatch setup を実行します。その後は従来の設計図登録・準備・開始の操作を使用できます。
5. 元に戻すときはサーバーを停止し、level-name を元のワールド名へ戻して再起動します。

既存ワールドでデータパックだけ交換しても、生成済みの溶岩は消えません。新旧の地形が混ざるため、比較には別の新規ワールドを使ってください。既存の船・地形を削除する処理は含めていません。

## 動作確認

別の新規試験ワールドで、奈落の生成、ロビー生成、ドック生成を確認済みです。船・NPC付きでの溶岩版との負荷比較はまだ実施していません。本番への切り替えはしていません。
