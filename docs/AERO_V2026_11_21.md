# v2026.11.21 — 投下後の鉄柵撤去

記録済みの爆弾取り付け位置に残ったminecraft:iron_barsだけを、整備員が歩いて到達してから撤去。残骸撤去では補給品を要求/消費せず、鉄柵アイテムも生成しない。その後の再装着では従来どおり実物の爆弾・信管を要求し消費する。

- 登録位置以外の鉄柵、支持ブロック、他の材質は除去しない。
- 記録位置が同じ機体にあり、支持部分と再装着条件が有効な場合のみ対象。
- 飛行任務中・発射信号が入っているときは撤去しない。作業前後で対象を再確認し、別のブロックに変わっていれば中止。

別環境で実際のSable機体とCBCMS HE爆弾を使い、鉄柵撤去→実物爆弾の消費/再装着、周辺の鉄柵の保持、石/鉄ブロック/ガラスの保持、作業中の変更・通電・飛行中の拒否を確認。試験物は終了時に片付けた。
本番には2クラスを同時に更新して再起動なしで適用。永続JARも更新。参加用インスタンスはゲーム終了後に差し替え。

C-1の割り当てと空席は有効、座席まで約44ブロック。出発地点で左右の乗員、約1.12ブロックの段差（現行上限1.05）、頭上の安山岩ケーシングにより四方向が通行不可となり、探索が1ノードで終了していた。船のブロックや乗員の配置は変更していない。
