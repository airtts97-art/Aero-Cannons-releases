# v2026.11.22-13 ベッド上からの経路探索

ワーカー探索の出発点判定を修正しました。ベッド上の足元は整数の高さではなく、旧実装ではベッドの内部のセルを出発点として選び、衝突判定で「塞がっている」と扱っていました。

取得済みの衝突情報から上下の候補を少数確認し、実際の足元の高さに最も近い歩行可能な足場を出発点にします。通常の床での微小な位置ずれにも対応し、壁の中など歩けない場所を無条件で通行可能にはしません。経路計算は引き続き専用ワーカーで行います。

別環境のSable船上で、ベッド上にいる兵士に移動命令を与え、ベッドから降りて甲板上の目標付近へ到達し、着地するところまで確認しました。ベッド・下付きハーフ・カーペットの足場選択、通常床の微小な位置ずれ、塞がった出発点の拒否も判定試験で確認しています。すべての形状ブロックや航行条件を網羅した試験ではありません。

今回はJAR単体の更新です。ホストを終了し、ワールドをバックアップしてから旧Aero Cannons JARと差し替え、再起動してください。前提MODの変更はありません。複数船体の配置高度補正などv2026.11.22-12までの修正も含みます。
