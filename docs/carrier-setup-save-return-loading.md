# 機体設定の保存・帰還操作・Sable機体読み込み

## 保存修正
- 同じハブを選び直しても操縦キーを消さない（ハブが1個なら切替ボタンを無効化）。
- 別ハブへ切り替えてもキー名を保持し、出力先だけを変更する。新しいハブにそのキーの配線がなければ保存時の既存検証でエラーとなる。
- 再読込、機体を切り替えて戻る操作でも未保存の編集を保持する。
- サーバーから保存完了と登録内容が返ってから、登録キー数を表示する。
- 応答待ち中は重複操作を止め、8秒応答がなければ編集を保持して再保存できる。
- 空選択でキーを明示的に解除する操作は維持する。

## 帰還
- 帰還・中止は座標欄を読み取らず送信しない。
- 帰還命令を送ったことを表示し、古い「座標が必要」というエラー表示を残さない。
- OPコマンド aeropilotnav <NPC> return も座標なしで名簿のある母艦を選べるようにする。
- 母艦には着艦用滑走路の登録と、機体には必要な操縦・脚入力の設定が必要。

## 読み込み
従来は通常ワールドの現在地・パイロット位置・進行方向に短期チャンクチケットを出すだけで、Sable機体専用の強制読み込み要求は発行していなかった。
飛行命令中はSableの専用APIによる機体チケットも維持する。
中止・命令終了・ゲームルールOFF・正常終了で自分の機体チケットを解除し、クラッシュ後に残った自分のチケットは次回起動で掃除する。
手動で設定された強制読み込みチケットには触れない。

## 診断
OPコマンド aeropilotnav <NPC> diagnose で、機体・NPCの位置、速度、角速度、操縦設定、観測プレイヤー数、専用チケットの有無、現在命令を取得する。

## 実機の飛行調査
試験機以外のA03で、推進入力と64～73m/sの速度を確認。一方、数秒間隔のサンプルでバンク角が約-104～+94度に往復した。
この記録は離陸直後の連続履歴ではないため、発生の瞬間や原因となる入力方向は未特定。
今回の更新だけで、全機体の離陸・巡航が安定したとはしていない。

## 確認範囲
Java 21コンパイルと実際のNBTを使用した保存編集処理の回帰試験を実施。
同一ハブ、別ハブ、編集中のキー、明示解除、爆弾の直接選択、保存キー数を確認。
ゲーム画面での保存操作・帰還ボタンの確認は未実施。起動中のクライアントJARは変更しない。
